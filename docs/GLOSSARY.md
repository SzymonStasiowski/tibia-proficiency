## Glossary

- Build: A user's selection set (equipment, imbuements, charms, perks) with metadata.
- Catalog: Reference data for items, imbuements, charms (no numeric effects in v1).
- Slot: Equipment positions: Head, Neck, Backpack, Armor, Weapon, Shield/Two-Hand, Legs, Feet, Ring, Ammo.
- Scraper: A script that extracts catalog entries from Tibia Wiki, validates, and upserts into Supabase.
